# BakeOven

烘焙占炉排程：发酵+烘烤半开区间占用炉位，冲突检测与下一可开工窗口。产品登记温度档，炉位登记换档预热分钟；换档批次开工前自动插入预热段（同占炉，不算发酵/烘烤），预热重叠报「预热冲突」。

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4500 |
| API | http://localhost:9500 |
| API 文档 | http://localhost:9500/docs |
| Postgres | localhost:5446 |

健康检查：`GET http://localhost:9500/api/health`

## 页面

- `/products` — 产品（配方时长、温度档）
- `/ovens` — 炉位（换档预热分钟）
- `/batches` — 批次（含本批温度档）
- `/gantt` — 甘特（预热/发酵/烘烤占炉）
- `/conflicts` — 冲突
- `/windows` — 可开工

## 使用说明

1. 在产品页登记各产品所需温度档，在炉位页登记换档所需预热分钟。
2. 创建生产批次，系统按半开区间占炉并检测冲突；新批次温度档与炉上紧邻上一档不同时，自动在其占炉前插入预热段。
3. 预热段同样占炉：与任何已有占炉（含他人预热）重叠即拒绝，报「预热冲突」；同档或炉上首批不插预热。
4. 甘特查看预热/发酵/烘烤占用；冲突与可开工窗口辅助排产。
